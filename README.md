# Yinghan Zhang

**Stone artist and printmaker** · 石头艺术家 · 版画家

[yinghanart.com](https://yinghanart.com) · [Instagram @mixiaoloartt](https://www.instagram.com/mixiaoloartt/)

---

This repository hosts the portfolio website of Yinghan Zhang (张樱瀚). Her work explores the cultural and philosophical meaning of scholars' stones through full-shape stone rubbing, water-based woodcut and handmade paper.

The site is available in English and 中文.
